macOS

macOS 26 or later. A universal app for Apple silicon and Intel Macs, signed and notarized by Apple.

Requirements

  • An iPhone or iPad on iOS / iPadOS 27 or later, over USB or Wi-Fi.
  • macOS 26 or later (the versions it is tested on; the terminal install warns on an older one).
  • Nothing else on the Mac: no Xcode, no other software.

Install the app

  1. Download DeviceSteer_universal.dmg, open it and drag DeviceSteer to Applications.
  2. Open DeviceSteer. On first launch it offers to set up agents: the devicesteer command (~/.local/bin/devicesteer) and the DeviceSteer skill for the coding agents it finds (Claude Code, Codex and others that read ~/.agents/skills, Cursor, GitHub Copilot CLI). Both are links into the app, so they update with it. Change this any time in Settings › Agents (⌘,).
  3. If it says ~/.local/bin isn't on your PATH, add export PATH="$HOME/.local/bin:$PATH" to your shell profile.

The app keeps itself up to date.

Or from a terminal

curl -fsSL https://github.com/sunghyun-k/devicesteer/releases/latest/download/install.sh | sh

It downloads the latest release, checks it against the release's SHA256SUMS and its code signature, and installs it in /Applications (~/Applications when that isn't writable). An installed copy is updated in place. Then it sets up the command and the skill, as Settings › Agents does, and prints what went where.

Options go after sh -s --:

  • --version 1.0.0: a given release instead of the latest.
  • --quit: quit a running DeviceSteer first (otherwise it stops and asks you to).
  • --dir <folder>: install somewhere else.
  • --no-agents: skip the command and the skill.

Later, devicesteer agents shows what is set up, and devicesteer agents install or uninstall changes it.

Windows

Windows 10 and 11, x64. Installs for your account only, without administrator rights.

Requirements

  • An iPhone or iPad on iOS / iPadOS 27 or later, over USB or Wi-Fi.
  • For USB: Apple Devices from the Microsoft Store (or iTunes), opened once with its license accepted. A device paired over Wi-Fi needs neither.

Install from PowerShell

irm https://github.com/sunghyun-k/devicesteer/releases/latest/download/install.ps1 | iex

It downloads the latest installer, checks it against the release's SHA256SUMS, installs it in %LOCALAPPDATA%\DeviceSteer and sets up the devicesteer command and the agent skill, as Settings › Agents does. A given version, or -NoAgents to skip the command and the skill:

& ([scriptblock]::Create((irm https://github.com/sunghyun-k/devicesteer/releases/latest/download/install.ps1))) -Version 1.0.0

Or run the installer

Download DeviceSteer_x64-setup.exe and run it. DeviceSteer isn't code-signed yet, so:

  • SmartScreen stops an installer a browser downloaded ("Windows protected your PC"): click More info, then Run anyway. The PowerShell install doesn't hit this.
  • Smart App Control (Windows 11) blocks unsigned apps however they arrive, with no exception for one app. While it is on, DeviceSteer can't be installed.

After installing

  • The devicesteer command is %USERPROFILE%\.local\bin\devicesteer.exe (the PowerShell install sets it up; with the installer, the app offers to on first launch). If %USERPROFILE%\.local\bin isn't on your PATH, add it to your user Path and open a new terminal.
  • Pairing a device over Wi-Fi makes Windows Firewall ask once whether DeviceSteer may accept connections: allow it on private networks.

The app keeps itself up to date. Before uninstalling, turn the items off in Settings › Agents: the uninstaller doesn't remove the links.

Next: set up your device

Connect an iPhone or iPad and select it in the app; it walks you through trusting the computer, Developer Mode and the developer tools. Or pair over Wi-Fi without a cable. Get started.
